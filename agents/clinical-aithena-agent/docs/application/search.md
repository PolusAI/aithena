# Search Trials

The Search Trials tab provides a way to browse and explore the full ClinicalTrials.gov database through GARDIAN's interface.

## Statistics Dashboard

At the top of the Search Trials view, a statistics dashboard provides an overview of the trial corpus:

- **Total Trials** — The number of clinical trials currently in the database
- **Conditions** — The number of distinct medical conditions represented across all trials
- **Phases** — Distribution of trials across study phases (Phase 1, 2, 3, 4, and others)
- **Interventions** — The number of distinct interventions (drugs, biologics, devices, procedures) being studied

These statistics are computed from the live database and reflect the most recent data sync.

## Browsing Trials

The search interface allows users to browse trials with:

- **Text search** — Search across trial titles, conditions, interventions, and summaries
- **Paginated results** — Trials are displayed in pages with navigation controls
- **Trial cards** — Each result shows the trial's NCT ID, title, status, phase, and key conditions at a glance

## Study Detail Pages

Clicking on a trial opens its full detail page, displaying the complete information from ClinicalTrials.gov:

- **Title and identifiers** — Brief title, official title, and NCT ID
- **Study overview** — Brief summary, detailed description, and study design
- **Conditions and interventions** — What conditions the trial addresses and what treatments are being studied
- **Eligibility criteria** — Full inclusion and exclusion criteria text
- **Study details** — Phase, enrollment, start and completion dates, sponsor information
- **Status** — Current recruitment status (recruiting, completed, terminated, etc.)

The detail page provides all the information a clinician or patient would need to evaluate whether a trial might be relevant, without leaving the GARDIAN interface.
